# Установка VoidGram

Статическая инструкция для iOS. На странице — выбор способа установки, шаги,
скриншоты, файлы и ответы на вопросы. Промоблоки и демонстрационные рендеры удалены.

Открой `dist/index.html` в браузере или запусти из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Адрес для просмотра: `http://127.0.0.1:4173`. Сборка и установка пакетов не нужны.
На статический хостинг выкладывается содержимое `dist/`. Существующий workflow
`.github/workflows/pages.yml` публикует его на GitHub Pages при пуше изменений сайта.

## Содержимое

- Установка через iLoader: шесть шагов, выбор Windows / macOS / Linux.
- Установка с сертификатом: пять шагов с инструкцией для бота.
- Выбор способа, ОС и пройденные шаги сохраняются в браузере.
- Прямые ссылки `#step-4` и `#cert-3`, кнопки назад/вперёд и сброс прогресса.
- Скриншоты открываются в диалоге в исходном размере.
- В шестом шаге можно переключать экраны настроек iOS.
- Без JavaScript показаны все шаги; ссылки на скачивание доступны.
- FAQ работает через стандартные HTML `details`.
- На телефоне навигация по шагам сворачивается до номеров.
- Подготовка и напоминание об обновлении подписи видны при выборе iLoader.

Страница не принимает Apple Account, пароли или коды. Авторизация и подпись IPA
происходят в iLoader на компьютере пользователя.

## Скриншоты

Изображения задаются в `screenshots` внутри `site-config.js`. Шаг принимает
объект или массив объектов с подписями для переключения экранов. Значение `null`
оставляет встроенную схему.

| Шаг | Изображение |
| --- | --- |
| iLoader, Windows | `assets/steps/01-iloader-windows.webp` |
| Apple Account | `assets/steps/04-apple-account.webp`, почта скрыта в самом файле |
| Выбор IPA | `assets/steps/05-select-ipa.webp` |
| Сертификат | `assets/cert/01-device.webp`, `02-tariff.webp`, `03-payment.webp` |
| Доверие компьютеру | Изображение [Apple Support](https://support.apple.com/109054) |
| Режим разработчика | Три изображения [Expo Docs](https://docs.expo.dev/guides/ios-developer-mode/) |

Изображения Apple и Expo требуют интернета. При ошибке загрузки остаются схема,
инструкция и ссылка на источник. Для автономной версии сохрани изображения
локально и обнови `src` в конфигурации, сохранив сведения об источнике.

## Анимации

У переходов единая кривая `cubic-bezier(.22, .7, .3, 1)` и короткие длительности:

- Появление заголовка и инструкции: 280 мс, сдвиг на 7 px.
- Смена шага, способа установки и инструкций ОС: 200 мс, сдвиг на 8 px.
- Изменение высоты панели: 240 мс.
- Подложка выбранной ОС: 180 мс.
- Прогресс: 230 мс; отметка выполненного шага: 160 мс.
- Открытие скриншота: 180 мс.
- FAQ: раскрытие за 230 мс, закрытие за 180 мс.

Повторное действие прерывает текущий переход. Поздняя загрузка изображения и
изменение ширины окна освобождают высоту панели. При `prefers-reduced-motion`
анимации отключаются, в том числе уже запущенные. Во время печати все шаги видны.

## Проверка

Проверено в Chromium: ширины 320, 360, 390, 540, 768, 1024 и 1440 px без
горизонтального переполнения; все шесть шагов iLoader и пять шагов сертификата;
выбор ОС; сохранение прогресса после перезагрузки; диалог скриншота; FAQ;
быстрое переключение способов; завершение анимации высоты; reduced motion;
доступность инструкции без JavaScript. Ошибок JavaScript, повторяющихся ID,
сломанных якорей и отсутствующих локальных изображений не обнаружено.
Safari и физический iPhone в этой проверке не использовались.
