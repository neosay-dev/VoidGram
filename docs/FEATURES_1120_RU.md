# Блок 1120 (исходники разработки)

Патч `patches/voidgram-features-1120.patch` накладывается последним (`ci/prepare.py`).
Опубликованные IPA этих изменений не содержат.

## Пользовательское соглашение

- Показывается перед экраном входа поверх всего окна (`AyuLicenseAgreement.swift`).
  Тем, кто уже вошёл в аккаунт до появления соглашения, оно показывается один раз при следующем запуске.
- Кнопка «Принимаю» включается, только когда текст долистан до последней строки (с допуском 2 pt).
  Если весь текст помещается на экране (большой iPad или Mac), кнопка включается сразу.
- Принятие хранится в `ayu.license.acceptedVersion`. Если увеличить `AyuLicenseAgreement.version`,
  соглашение попросят принять снова.
- «Не принимаю» показывает объяснение. Без согласия приложением пользоваться нельзя.

## Предупреждение в чатах

- Перед первым своим сообщением в чате VoidGram отправляет от имени пользователя предупреждение
  (`AyuChatNotice.textRu` / `textEn`, язык берётся из интерфейса). Это делается один раз на чат для каждого аккаунта.
  - В личных чатах сообщение закрепляется для обеих сторон (без уведомления).
  - В группах и супергруппах сообщение не закрепляется.
  - Не отправляется в «Избранное», ботам, служебным и удалённым аккаунтам, каналам, секретным чатам,
    отложенным сообщениям и в фейк-режиме.
- Удалить сообщение у отправителя нельзя. Фильтр стоит в `_internal_deleteMessagesInteractively`,
  поэтому работает для любого пути: меню, выделение, свайп, плагины. Пункт «Удалить» для него скрыт.
- Открепить у отправителя нельзя: «Открепить» скрыт, а `unpinMessage` отказывает.
  Если закреп снят иначе («Открепить все», другой клиент), он восстанавливается при открытии чата.
- Собеседник может удалить сообщение. Повторно оно не отправляется.
- Ограничение: «Очистить историю» с удалением у обоих удалит и это сообщение. Это отдельный серверный запрос.

## Энергосбережение

**Настройки → VoidGram → Ещё → Энергосбережение.** Есть отдельные профили для телефона, планшета и ноутбука
(Mac определяется через `isiOSAppOnMac`).

- Режимы: «Как в Telegram» (по умолчанию), «Никогда», «При низком заряде» (порог 5–95 %), «Всегда».
- Дополнительные условия: системный режим энергосбережения; «Всегда без зарядки» (удобно для ноутбука).
- Можно выбрать, что оставить включённым: видео, GIF, стикеры, эмодзи, размытие, работа в фоне, загрузки в фоне.
- Профиль заменяет настройки Telegram на этом устройстве в `SharedAccountContextImpl.energyUsageSettings`.

## Плеер

- «Написать свой текст» или «Изменить текст песни» в меню плеера (долгое нажатие на кнопку слов).
  Если слова не найдены, можно нажать на эту надпись.
  - Время в формате `[мм:сс.сс]` делает текст синхронным; без меток текст обычный и выравнивается по звуку.
  - Текст хранится в Application Support для каждой песни и перекрывает все источники.
  - «Вернуть найденный текст» удаляет свой. Импортированный LRC теперь тоже сохраняется.
- Ночной режим плеера (**Настройки → VoidGram → Медиа и звонки → Ночной режим плеера** или «Ночной режим → Настроить…» в меню плеера).
  - Фон становится темнее (по желанию теплее), белый текст и кнопки приглушаются.
  - Главный переключатель выключает режим полностью.
  - Режимы: по расписанию (часы начала и конца, окно может переходить через полночь; по умолчанию 22:00–07:00) или всегда.
  - Сила затемнения: слабо, средне или сильно. Тёплый или нейтральный оттенок. Сброс к стандартным значениям.
- Мини-плеер: пока играет трек с синхронным текстом, вместо названия показывается текущая строка
  («♪ строка», ниже «Название — Исполнитель»). Учитывается сдвиг синхронизации трека.
  Отключается пунктом «Строка песни в мини-плеере».
