## Как запустить / How to launch

### iPhone, iPad

**RU:** IPA без подписи, перед установкой его нужно подписать своим сертификатом: AltStore, SideStore, Sideloadly, ESign или TrollStore. После установки открой VoidGram и войди в аккаунт. Настройки: Настройки Telegram → VoidGram.
**EN:** the IPA is unsigned, sign it with your own certificate before installing: AltStore, SideStore, Sideloadly, ESign or TrollStore. After installing, open VoidGram and sign in. Settings: Telegram Settings → VoidGram.

### Windows 10/11

**RU:**
1. Скачай `voidgram-desktop-windows-x64.zip` и распакуй в любую папку (например, `C:\VoidGram`).
2. Запусти `VoidGram.exe`. Установка не нужна.
3. Если Windows пишет «Система Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае»: файл без цифровой подписи.
4. Войди по номеру телефона или QR-кодом. Данные хранятся в `%APPDATA%\AyuGram Desktop`.

**EN:**
1. Download `voidgram-desktop-windows-x64.zip` and unpack it anywhere (for example `C:\VoidGram`).
2. Run `VoidGram.exe`. No installation is needed.
3. If Windows says "Windows protected your PC", click "More info" → "Run anyway": the file has no digital signature.
4. Sign in with your phone number or a QR code. Data lives in `%APPDATA%\AyuGram Desktop`.

### macOS

**RU:**
1. Скачай `voidgram-desktop-macos-universal.dmg`, открой его и перетащи VoidGram в «Программы».
2. Приложение подписано только локально (без сертификата Apple), поэтому первый запуск такой: правый клик по VoidGram → «Открыть» → «Открыть». Если macOS пишет, что приложение «повреждено», выполни в Терминале: `xattr -dr com.apple.quarantine /Applications/VoidGram.app` и запусти снова. На новой macOS может понадобиться «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
3. Одна сборка для Intel и Apple Silicon, работает на macOS 10.13 High Sierra и новее (Mac 2012 года, обновлённые до 10.13–10.15, тоже подходят). Для очень старых Mac отдельного файла нет: качай тот же `.dmg`, а если он не открывается, `.zip`. macOS 10.12 и старше не поддерживается. Проверено по бинарнику: на Intel минимум 10.13, на Apple Silicon 11.0, без Swift и без Translation.framework.

**EN:**
1. Download `voidgram-desktop-macos-universal.dmg`, open it and drag VoidGram to Applications.
2. The app is signed only locally (no Apple certificate), so the first start is: right click VoidGram → Open → Open. If macOS says the app is "damaged", run `xattr -dr com.apple.quarantine /Applications/VoidGram.app` in Terminal and start it again. On a recent macOS you may also need System Settings → Privacy & Security → Open Anyway.
3. One build for Intel and Apple Silicon; it runs on macOS 10.13 High Sierra and newer (a 2012 Mac updated to 10.13–10.15 is fine). There is no separate file for very old Macs: take the same `.dmg`, or the `.zip` if it will not open. macOS 10.12 and older is not supported. Checked in the binary: minimum 10.13 on Intel, 11.0 on Apple Silicon, no Swift and no Translation.framework.

### Linux

**RU:** одна команда для любого дистрибутива. Скрипт сам узнаёт систему: на Arch ставит сборку для Arch в `~/.local`, на Debian и Ubuntu — `.deb` через apt, на Fedora и RHEL — `.rpm` через dnf, на openSUSE — через zypper, на остальных — общую сборку в `~/.local`. Для `.deb` и `.rpm` спросит пароль sudo. Та же команда обновляет VoidGram. После установки найди VoidGram в меню приложений или запусти `VoidGram` в терминале.
**EN:** one command for any distribution. The script finds out the system: on Arch it installs the Arch build into `~/.local`, on Debian and Ubuntu the `.deb` through apt, on Fedora and RHEL the `.rpm` through dnf, on openSUSE through zypper, elsewhere the generic build into `~/.local`. For `.deb` and `.rpm` it asks for the sudo password. The same command updates VoidGram. Afterwards find VoidGram in the application menu or run `VoidGram` in a terminal.

```
curl -fsSL https://raw.githubusercontent.com/neosay-dev/VoidGram/main/desktop/install.sh | bash
```

Без sudo, только в `~/.local` / Without sudo, into `~/.local` only:

```
curl -fsSL https://raw.githubusercontent.com/neosay-dev/VoidGram/main/desktop/install.sh | bash -s -- --local
```

Удаление / Uninstall:

```
curl -fsSL https://raw.githubusercontent.com/neosay-dev/VoidGram/main/desktop/install.sh | bash -s -- --uninstall
```

Вручную / By hand: `sudo apt install ./voidgram-desktop-x86_64.deb` (Debian, Ubuntu), `sudo dnf install ./voidgram-desktop-x86_64.rpm` (Fedora).

**RU:** на Arch сначала обнови систему (`sudo pacman -Syu`), иначе может не найтись `libssl.so`. Данные лежат в `~/.local/share/AyuGramDesktop` и общие с AyuGram Desktop: не запускай оба клиента одновременно.
**EN:** on Arch update the system first (`sudo pacman -Syu`), or `libssl.so` may be missing. Data lives in `~/.local/share/AyuGramDesktop`, shared with AyuGram Desktop: do not run both at once.
