# VoidGram для Android

Основа — официальный Telegram для Android 13.2.2 (`android/upstream.json`, коммит `21f7d109`).
`android/prepare.py` проверяет коммит, накладывает `android/patches/*.patch` и ресурсы, затем ставит брендинг:
- package id `one.voidgram.android` (standalone-сборка `.web`), имя VoidGram;
- ключи API VoidGram из секретов `TELEGRAM_API_ID`/`TELEGRAM_API_HASH`;
- без обновлений на APK Telegram;
- собственный тип аккаунта контактов.

Сборка: `.github/workflows/android.yml` собирает APK под armeabi-v7a и arm64. Свой ключ подписи задаётся секретами
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`; без них APK подписан тестовым ключом из исходников Telegram.
Push-уведомления через Firebase в стороннем package id не приходят.

## Ещё не перенесено

- Плагины (JS, Python, Lua, Rust) и каталог.
- Оформление: темы и палитры VoidGram, скины пузырей, стекло, стили ников, рамки аватарок, NFT, скрытие вкладок.
- Синхронизация текста по словам, распознавание трека (Shazam), очередь, вибрация в такт.
- Редактор скриншотов, →A (голос в текст), мульти-ответ, визуальная цитата, «чёрная дыра».
- Подарки (рынок, действия), запикивание мата, экспорт чатов.

Синтаксис Java проверяется локально через `javac`. Компиляция проверяется только сборкой в GitHub Actions.
